The accounts' icons: emoji redrawn in typed characters and painted, the way Phantom lets you give an account an emoji.
Every icon fits a 15 x 9 box (anything bigger is refused) and is centred in it, so they all draw the same size. They
are set at line-height 1, so | / \ ( ) and _ join up into solid lines.

Colours are the ":: letter #hex name" lines below. An icon is "== id", then its legend, then its art written in source
characters. A legend line ": src [shown] colour" paints every src character in that colour and, if it names a second
character, shows that one instead (": 1 # g" draws each 1 as a green #); ": * colour" paints everything the legend
doesn't name. Spaces stay empty, so the dark shows through (the ghost's eyes, the pig's nostrils).

  node scripts/account-icons/build.mjs      writes src/shared/icons.js (edit this file, not that one)
  node scripts/account-icons/preview.mjs    writes shots/icons-all.png, to judge them
